Ensembling the CDA scorers

Date: 13/09/2026

GOHREP

Goal:

Test whether combining several trained scorers beats using one. Seven ensembles are tried. Each starts from something observed about the models, not from the fact that ensembling is a standard thing to do.

Hypothesis:

Combining will not raise accuracy much. Every member is trained on the same 1,834 crops, and analyses/10 §3 already found the top-100 CNNs give the same score as each other on 77.9% of test crops. Averaging cannot fix a mistake the members share.

One gain is expected, in §5. Cross-validated near-miss accuracy is 0.966-0.985 across the tied members of all three grids (recorded in each grid’s random_search_results.csv), so nearly all the error left is off by one. A rule that can return the value between two neighbouring answers has something to work with that a vote does not.

§6 and §7 are both fitted to the 455 ensemble crops, so both are expected to look good there and lose most of it on test.

Rationale:

The seven ideas, one section each. “Known” means established before this analysis and cited; “conjecture” means the section measures it before testing it.

§ Idea Why try it Basis
2 Vote over the 22 tied CNNs At least one of 100 CNNs is right on 93% of test crops against 66% for the best one Known (analyses/10 §3.5)
3 Mix model families A CNN, a transformer and a 12-feature regression may fail on different crops Conjecture, measured in §3.1
4 Mix training data, keep the architecture The augmented CNNs were trained on a different set of crops Known (models/07 builds from medoid_64_aug)
5 Average the score instead of voting on it Scores are ordered, and near-miss is 0.966-0.985, so nearly every error is off by one Known (grid avg_val_nearmiss)
6 Pick members that disagree Top-100 CNNs give the same score on 77.9% of crops, so members are near-duplicates Known (analyses/10 §3.5)
7 Learn who to trust at each score Families may be good at different scores Conjecture, measured in §7.1
8 Decline the crops it is unsure about Disagreement may mark the crops it gets wrong Conjecture, measured in §8.1

Every choice — members, rule, hyperparameters, committee size — is made on the ensemble split (455 crops, held out of all training). test (308 crops) is scored once at the end. Both are shown so the drop between them is visible.

# A grid's single best config is not reproducibly the best: on 2,289 cross-validation
# crops the standard error near 0.65 is about 1.0 pp, and each grid has many configs
# inside that of its own winner. So each family contributes every config within one

# `ensemble` or `test`.

# 1.6
def exact(pred, y):
    return float(np.mean(pred == y))

def near(pred, y):
    return float(np.mean(np.abs(pred - y) <= 1))

def mae(pred, y):
    """Mean absolute error in score units. The natural loss for an ordinal target: it
    charges a 0-scored-as-6 seven times what it charges a 3-scored-as-4, which neither
    exact nor near-miss accuracy does."""
    return float(np.mean(np.abs(pred - y)))

def plurality(P):
    """P: (models, images) hard scores -> the modal score per image."""
    return np.array([np.bincount(P[:, j], minlength=7).argmax() for j in range(P.shape[1])])

def mean_prob(Q):
    """Q: (models, images, 7) softmax -> argmax of the member-averaged distribution."""
    return Q.mean(0).argmax(1)

def expected_score(Q):
    """Q -> the mean of the averaged distribution, rounded to the nearest score."""
    return np.clip(np.rint((Q.mean(0) * np.arange(7)).sum(1)), 0, 6).astype(int)

def family_mean(Qs):
    """Average within each family first, then across families, so a 51-model family
    does not outvote a 1-model family purely by count."""
    return np.stack([q.mean(0) for q in Qs]).mean(0)[None]

SE_E, SE_T = np.sqrt(0.65 * 0.35 / len(ye)), np.sqrt(0.65 * 0.35 / len(yt))
print(f"1 SE on the ensemble split ({len(ye)} crops) = {100 * SE_E:.2f} pp")
print(f"1 SE on the test split ({len(yt)} crops)     = {100 * SE_T:.2f} pp")

# 1.6b
RNG = np.random.default_rng(0)
BOOT = RNG.integers(0, len(yt), size=(10000, len(yt)))

def paired_ci(a, b, y=None):
    """95% CI and two-sided p for accuracy(a) - accuracy(b) over the same crops."""
    y = yt if y is None else y
    da, db = (a == y).astype(float), (b == y).astype(float)
    d = da[BOOT].mean(1) - db[BOOT].mean(1)
    p = min(1.0, 2 * min((d <= 0).mean(), (d >= 0).mean()))
    return float(da.mean() - db.mean()), float(np.quantile(d, .025)), float(np.quantile(d, .975)), float(p)

# 3.1
# Two ways to measure whether models fail alike. Raw agreement is how often they give the
# same score. The joint-error ratio is how often both are wrong on the same crop, divided
# by how often they would be if their mistakes were unrelated. 1.0 means unrelated;
# higher means shared blind spots.
HARD_E = {k: v["e"].argmax(2) for k, v in FAM.items()}
HARD_T = {k: v["t"].argmax(2) for k, v in FAM.items()}
names = list(FAM)

def pair_stats(A, B, y, same):
    ag, ratio = [], []
    for i in range(A.shape[0]):
        for j in range(B.shape[0]):
            if same and j <= i:
                continue
            ag.append(np.mean(A[i] == B[j]))
            ea, eb = A[i] != y, B[j] != y
            indep = ea.mean() * eb.mean()
            ratio.append(np.mean(ea & eb) / indep if indep > 0 else np.nan)
    return np.array(ag), np.array(ratio)

rows = []
for i, a in enumerate(names):
    for b in names[i:]:
        if a == b and HARD_E[a].shape[0] < 2:
            continue
        ag, rt = pair_stats(HARD_E[a], HARD_E[b], ye, same=(a == b))
        rows.append({"pair": f"{a} vs {b}" if a != b else f"{a} (within)",
                     "kind": "within" if a == b else "across",
                     "n pairs": len(ag), "mean agreement": ag.mean(),
                     "joint-error / independent": np.nanmean(rt)})
corr = pd.DataFrame(rows).sort_values("joint-error / independent")

10. Interpretation and Discussion

  • The oracle gap is not spare accuracy (§2). At least one of the 22 tied CNNs is right on 89.67% of ensemble crops against a best single of 63.96%. Almost none of that is reachable: on 97.5% of the crops where some member is right but the vote is not, the correct score is a minority answer, a median of 4.5 members of 22. A vote returns the most common answer, so those crops are out of reach. The vote lands at 64.94% on test against 64.61% for the best of the 22.
  • Different families do fail differently, and it is not worth much (§3). The four lowest joint-error ratios are all across families (CNN–ViT 1.754 lowest) and the two highest are within one family (augmented CNN 2.176, CNN 1.933). Mixing all four gives 66.88% on test: 3.9 pp above the average single member, and level with the best one.
  • Different training data decorrelates less than a different architecture (§4). CNN against augmented CNN is 1.909, CNN against ViT is 1.754. Same architecture on different crops stays more alike than a different architecture on the same crops. The accuracies follow: CNN + augmented CNN is the worst pair at 65.26%, below CNN + ViT at 67.86% and CNN + ordinal regression at 68.18%.
  • Averaging the score beats voting on it (§5). The two rules differ on 52 of 455 ensemble crops. On those the average is right 55.77% of the time against the vote’s 40.38%, mean error 0.442 against 0.635. It wins on the split used to choose (65.71% against 65.49% for the argmax and 63.96% for the vote) and stays ahead on test: 68.51% exact and mean error 0.328, both the best of any rule here. Its near-miss, 98.70%, is not the best — the chapter’s single model reaches 99.03%.
  • Picking members for disagreement does not work (§6). Greedy selection’s first pick is already the best single member at 70.33%, and over 25 steps the curve only moves between 69.23% and 70.77%, a 1.54 pp range against a 2.24 pp standard error, so choosing k is choosing noise. Its k = 3 committee drops 5.83 pp on test where the average rule gains 0.34 pp. Adding to a lucky model on the split that made it look lucky does not help either: the ranked curve starts at the same 70.33% and is down to 68.57% by five members.
  • A learned combiner cannot use the per-score differences (§7). They are real: on score 2 the ordinal regression reaches 0.569 against the CNNs’ 0.462, on score 5, 0.662 against 0.515. But 455 rows force regularisation (C = 0.1; by C = 10 the train-to-CV gap is 8.8 pp), and it gains 0.33 pp on test, CI −3.25 to +3.90. Shuffled labels give 0.145 against a chance rate of 0.143, so the fit is real, just small.
  • Declining uncertain crops is the one thing a committee can do that a single model cannot (§8). Accuracy rises from 50.0% on the 20 crops where under half the members agree to 78.8% on the 132 where over 90% do. Thresholds set on the ensemble split transfer: the cut giving 75.3% at 64.8% coverage there gives 73.5% at 66.2% on test. Declining the least-agreed 10% lifts the committee from 66.88% to 68.95%, which is the human raters’ 68.92%; declining half gives 75.97%.
  • No rule beats a good single model, but every rule beats a badly chosen one (§9). Every paired-bootstrap interval spans zero and the smallest p is 0.34. The one significant comparison runs the other way: the model that looked best on the ensemble split, at 70.33% there, falls to 62.34% on test — 4.55 pp below the chapter’s selected model, CI −8.77 to −0.33, p = 0.040. Single models from this pool span 56.82% to 67.53% on test while every fixed rule lands between 64.61% and 68.51%. Combining removes the risk of picking the wrong model; it does not raise the ceiling.

Recommendation

Two things are worth taking into the chapter, for different reasons.

  1. Family-balanced mean softmax, decided by expected score (§5). Highest exact accuracy and lowest mean error of anything tested, it also won on the split used to choose it, and it is justified by the ordinal label rather than by its score. Report it as level with the best single model, not above it.
  2. The declining curve (§8). The only result where a committee does something a single model cannot.

Everything else here is a negative result with a reason. One paragraph between them.

Caveats

  • Test is 308 crops, so one standard error is 2.72 pp. Rules within about 5 pp of each other are not separable.
  • 13 rules were scored on 455 selection crops, so the best of them is optimistic by construction. §9.4 measures that rather than assuming it away.
  • The augmented grid contributes 17 of its 18 tied configurations. Model 1440 ranks 9 of 8,640 on avg_vaf_orig but 161 on avg_vaf, and TopNStore (src/results_store.py) keeps the top 100 by avg_vaf, so its weights were never written on the cluster or here.
  • The cGAN-augmented grid and the soft-label grid are absent: neither has a saved set of tied models.
  • Labels are the recorded median human scores, which analyses/10 §4 shows are wrong on a handful of test crops.
